# Networking Practice Labs

Cisco Packet Tracer labs built to practice and reinforce core networking concepts covered in CCST Networking and beyond. Each subfolder contains the topology, configuration files, and notes for that lab.

## Labs

| Lab | Focus |
|---|---|
| [`DHCP`](./DHCP) | Dynamic IP address assignment — DHCP server/relay configuration |
| [`InterVLAN-Routing-Lab`](./InterVLAN-Routing-Lab) | Routing between VLANs using router-on-a-stick / L3 switching |
| [`Ospf`](./Ospf) | OSPF configuration and route propagation across multiple routers |
| [`RipV2`](./RipV2) | RIPv2 configuration and distance-vector routing behavior |

## Purpose

These labs are reproducible practice environments — not production configs — meant to demonstrate hands-on understanding of routing and addressing protocols beyond theory. Each lab folder includes the Packet Tracer topology file and supporting configuration notes.
