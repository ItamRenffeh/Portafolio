# Personal Automation Tools

A collection of scripts built for personal daily use rather than for a specific book chapter — practical automation that shows range beyond the security/networking focus of the rest of this portfolio.

## Projects

| Project | Focus |
|---|---|
| [`Daily Dashboard Generator`](./Daily%20Dashboard%20Generator) | Pulls weather, currency rates, GitHub trending, and news (RSS) into one generated HTML page |
| [`Modo Setup`](./Modo%20Setup) | Launches GitHub Desktop and a fixed set of study-session browser tabs with one command |

## Why this folder is separate

The rest of this portfolio follows a clear progression tied to security and networking concepts. These tools don't fit that thread — they're everyday automation built to solve small real friction points (starting a study session, getting a daily briefing) — but they demonstrate skills that are still relevant: consuming multiple API/data formats (JSON, HTML, XML/RSS), error handling, and scripting OS-level tasks.

## Requirements

Python 3.10+. Check each project's own README for specific dependencies.
