# Universidad - Proyectos

Carpeta que contiene todos los proyectos realizados durante la carrera universitaria, incluyendo trabajos de ciberseguridad, redes, programación y operaciones de seguridad.

## Proyectos Incluidos

### Estructuras de Datos
- **EstructurasDatosSegundoCuatrimestre** - Proyectos de estructuras de datos del segundo cuatrimestre
- **EstructurasSegundoCuatrimestre** - Estructuras avanzadas del segundo cuatrimestre
- **Estructuras-Eclipse** - Proyectos de estructuras realizados en Eclipse

### Programación
- **Java** - Proyectos y ejercicios en Java
- **TDas** - Trabajos de estructuras de datos y algoritmos

### Seguridad y Redes
- **SegundoCuatri** - Proyectos del segundo cuatrimestre de seguridad/redes
- **Mediapipe-Proyecto** - Proyecto con Mediapipe para análisis de video/visión por computadora

### Interfaces y Proyectos Integradores
- **ProyectoInterfaz** - Proyecto de desarrollo de interfaces
- **ProjectoInterfaz-main** - Proyecto integrador principal de interfaz (Allendeacc)

## Cómo Usar

Cada subcarpeta contiene un repositorio independiente con su propio histórico de commits. Para obtener los contenidos:

```bash
git submodule update --init --recursive
```

Para clonar este repositorio con todos los submodulos:

```bash
git clone --recurse-submodules https://github.com/ItamRenffeh/portfolio.git
```
