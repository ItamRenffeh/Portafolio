# Mediapipe - Proyecto

Proyecto de visión por computadora utilizando Google Mediapipe.

## Descripción
Este proyecto implementa soluciones de visión por computadora y análisis de video utilizando la librería Mediapipe de Google, incluyendo detección de poses, manos y rostros.

## Repositorio Original
🔗 [Ver repositorio completo](https://github.com/ItamRenffeh/Mediapipe-Proyecto)

## Tecnologías
- Python
- Google Mediapipe
- OpenCV
- Visión por Computadora

## Contenido Principal
- Detección de poses humanas
- Seguimiento de manos
- Detección de puntos faciales
- Análisis de video en tiempo real

## Requisitos
```bash
pip install mediapipe opencv-python
```
