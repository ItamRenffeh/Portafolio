# TDAs - Tipos de Datos Abstractos

Proyectos relacionados con la implementación y uso de Tipos de Datos Abstractos (TDAs).

## Descripción
Este proyecto se enfoca en la abstracción de datos y la implementación de TDAs como listas, pilas, colas y árboles, entendiendo su funcionamiento interno y aplicaciones.
