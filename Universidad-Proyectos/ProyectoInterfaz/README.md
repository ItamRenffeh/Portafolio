# Proyecto Interfaz

Proyecto de desarrollo de interfaces de usuario.

## Descripción
Este proyecto se enfoca en el diseño e implementación de interfaces de usuario funcionales y atractivas, aplicando principios de UX/UI y programación de interfaces gráficas.

## Repositorio Original
🔗 [Ver repositorio completo](https://github.com/ItamRenffeh/ProyectoInterfaz)

## Tecnologías
- Interfaz Gráfica de Usuario (GUI)
- Diseño de UX/UI
- Desarrollo Frontend

## Contenido Principal
- Diseño de interfaces
- Interacción usuario-aplicación
- Principios de usabilidad
- Prototipos y mockups
