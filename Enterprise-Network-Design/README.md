# Enterprise-Network-Design

Repository for enterprise network designs, guides, and configuration templates.

Contents:

- design-guides/ (design documents, architectural decisions)
- diagrams/ (PNG/SVG/Draw.io diagrams)
- templates/ (configuration templates for routers, switches, firewalls)

Goal:
- Centralize best practices and design patterns applicable to enterprise infrastructure.

How to use:
- Review the guides in `design-guides/` before applying templates.

Contributing:
- Add clear diagrams and justify design decisions in your commits.
