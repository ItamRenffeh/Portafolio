# Network-Troubleshooting-Playbook

A playbook for network troubleshooting: procedures, commands, and checklists.

Typical sections:

- checklists/ (quick diagnostic checklists)
- common-issues/ (symptoms, root causes, and solutions)
- commands/ (frequent commands by vendor and how to interpret output)
- escalation/ (criteria and steps to escalate to advanced support)

Quick example:
1. Verify basic connectivity: `ping`, `traceroute`.
2. Check ARP/MAC tables and routing tables.
3. Inspect device logs and centralized syslog.

Contributing:
- Document each case with reproducible symptoms and clear resolution steps.
- Include command outputs and anonymized configurations when possible.
